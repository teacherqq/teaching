# 丝绸之路 The Silk Roads

给 9 年级国际学校学生的丝绸之路动画，共 9 个场景，全程楷体，配中文旁白和五声音阶背景音乐，最后是 4 题小测验。

## 打开方式

- 在线：开启 GitHub Pages 后访问仓库的 Pages 地址。
- 本地：直接双击 `index.html`，用浏览器打开。

打开后先点"🔊 开启配音和音乐"，声音才会出来（浏览器不允许网页自动播放声音）。

## 操作

- ⏮ ⏸ ⏭：上一场 / 暂停 / 下一场；也可以点进度条跳到任意一场
- 键盘：← → 翻页，空格暂停或继续
- 🔊 / 🎵：单独开关配音和背景音乐

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 动画页面（背景音乐由代码实时合成，不需要音频文件） |
| `audio/01.mp3`、`audio/02.mp3` | 场景 1、2 旁白 |
| `audio/03-1.mp3` … `audio/03-7.mp3` | 场景 3 地图逐站字幕 |
| `audio/04.mp3` … `audio/08.mp3` | 场景 4–8 旁白 |
| `audio/09-q*.mp3` | 小测验题目 |
| `audio/09-ok.mp3`、`audio/09-no.mp3` | 答对 / 答错提示 |
| `audio/09-e*.mp3` | 每题解释 |
| `audio/09-s0.mp3` … `audio/09-s4.mp3` | 得分总结 |

配音由 ElevenLabs 生成。
